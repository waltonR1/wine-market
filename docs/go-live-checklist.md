# 联调与上线检查清单

更新时间：2026-03-28

## 1. 文档目的
本文件用于把“联调前准备、联调过程、上线前检查、上线后观测”拆成可执行清单。

适合在以下阶段使用：
- 准备接真实后端前
- 联调进行中
- 提测前
- 发布前
- 上线后一周内观察

---

## 2. 联调前准备清单

### 2.1 接口与字段
- 明确页面与接口对应关系
- 输出接口清单
- 输出字段字典
- 输出状态码与错误码说明
- 输出订单状态流转说明
- 输出支付、物流、售后、评论字段说明

### 2.2 鉴权与环境
- 确认当前联调环境是 `mock / test / prod` 中哪一个
- 确认 `config/env.ts` 当前显式环境值
- 确认 `config/app.ts` 当前业务开关
- 确认登录态注入方式
- 确认 token 失效处理策略

### 2.3 样例数据
- 登录样例账号
- 商品样例
- 各订单状态样例
- 各售后状态样例
- 评论样例
- 用户资产样例

### 2.4 前端准备
- mock 与真实接口切换方案明确
- 请求层错误处理已统一
- 关键页面 loading / empty / error 已补齐
- 订单调试工具是否保留到 test 环境已确认

---

## 3. 联调顺序建议
建议不要同时全面铺开，按依赖顺序推进：

1. 登录 / 用户信息
2. 商品列表 / 详情 / 搜索
3. 收藏 / 足迹 / 优惠券
4. 购物车
5. 确认订单
6. 提交订单
7. 支付
8. 订单列表 / 订单详情
9. 评论
10. 售后
11. 物流

---

## 4. 联调过程中重点核对项

### 4.1 通用问题
- 字段缺失
- 字段名不一致
- 字段类型不一致
- 空值处理不一致
- 时间格式不一致
- 分页字段不一致
- 错误码语义不一致

### 4.2 用户系统
- 未登录拦截是否一致
- 登录失效是否统一跳转
- 用户信息是否缺字段

### 4.3 商品系统
- 列表筛选参数是否一致
- 排序字段是否一致
- 搜索结果空态是否有区分

### 4.4 订单系统
- 状态码是否一致
- 状态文案是否以后端文案还是前端规则为准
- 时间字段是否完整
- 物流字段是否完整
- 评价字段是否完整

### 4.5 售后系统
- 售后状态码是否一致
- 审核驳回原因字段是否明确
- 时间线节点是否能稳定返回

---

## 5. 联调期间前端收尾项
- 补 toast 文案
- 补 modal 文案
- 补 loading 态
- 补 empty 态
- 补 error 态
- 补异常分支兜底
- 清理临时联调兼容逻辑
- 记录真实接口与 mock 差异

---

## 6. 提测前检查清单

### 6.1 功能闭环
- 登录闭环
- 搜索 / 筛选 / 排序闭环
- 购物车闭环
- 下单闭环
- 支付闭环
- 订单闭环
- 评论闭环
- 售后闭环

### 6.2 关键边界
- 未登录访问
- 库存不足
- 地址缺失
- 支付失败
- 物流为空
- 售后驳回
- 评论为空 / 图片为空

### 6.3 工程检查
- 构建通过
- mock 启动正常
- 关键页面无明显 TS 报错
- 配置切换可用
- 无明显残留死代码

---

## 7. 上线前检查清单

### 7.1 配置与环境
- `env.ts` 当前环境值确认
- `app.ts` 当前业务开关确认
- 生产环境不暴露调试入口
- 高风险调试能力关闭
- 请求日志关闭
- mock 路径未误发

### 7.2 文案与页面
- 页面标题检查
- 按钮文案检查
- 状态文案统一检查
- 空态文案检查
- 错误提示文案检查

### 7.3 数据与安全
- 测试账号处理
- 测试订单处理
- 测试支付数据隔离
- token 存储策略确认
- 本地 mock 能力不会误进入生产链路

### 7.4 发布准备
- 版本号更新
- 更新说明整理
- 回滚方案准备
- 上线负责人明确
- 观测负责人明确

---

## 8. 上线后观测清单

### 8.1 重点指标
- 登录成功率
- 下单成功率
- 支付成功率
- 订单详情加载成功率
- 售后申请成功率
- 页面白屏 / 崩溃情况

### 8.2 用户反馈
- 客服入口可用
- 常见问题说明可用
- 订单问题反馈入口可用

### 8.3 上线后一周内收尾
- 收集真实用户问题
- 清理联调期间临时兼容逻辑
- 评估首页与推荐位是否需要基于真实数据调整

---

## 9. 当前项目特别需要关注的上线前项
结合当前项目现状，上线前务必重点确认：
- 用户系统是否已真正闭环
- 商品搜索 / 筛选 / 排序是否已完成
- 评论是否已切到按商品逐项评论
- 首页重做方案是否落地
- 真实微信支付是否已完成
- 真实物流系统是否已完成
- 订单调试工具是否已对生产关闭
- mock 数据与真实接口兼容逻辑是否已清理

---

## 10. 使用建议
建议使用方式：
- `next-phase-todo.md` 管整体路线
- 本文件管联调与上线执行
- 每次联调问题单独登记，不要只留在聊天记录里
